# Página Web Personal

## Descripción
Este proyecto consiste en el desarrollo de una página web personal utilizando tecnologías básicas de frontend. 
Incluye secciones como presentación, habilidades y contacto.

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript (opcional)

## Vista previa
Puedes abrir el proyecto localmente en tu navegador.

## Instalación
Clona este repositorio:

git clone https://github.com/tu-usuario/tu-repositorio.git

## Uso
1. Ingresa a la carpeta del proyecto
2. Abre el archivo `index.html` en tu navegador
